# Credits — Retro Space Shooter

## Audio (v4.2.0+)
All sound effects and music are synthesized at runtime with the Web Audio API
(oscillators, noise buffers, filters, and a generated-impulse ConvolverNode reverb).
No external audio files are downloaded or redistributed.

- SFX: cinematic sci-fi blasters, explosions, pickups, bomb blast, boss warning, etc.
- Music: procedural synthwave pads / bass / arpeggios (explore, boss, and menu states).
