# Retro Space Shooter (v2.1)

Mobile-first arcade shooter (v2.1). Levels/waves: clear enemies to advance — each level starts slow then ramps, with a slightly higher start each time. Dart is rarer and slower. Defend your homeland space station: enemies that slip past drain HOMELAND POWER; at zero you lose a life. Collisions and enemy fire also cost a life. Distance and speed ramp up; new enemy types appear as you fly farther (Diver, Weaver 250m, Zig-Zag 600m, Dart 1000m, Swooper 1500m, Tank 2200m).

- **Move**: drag anywhere (thumb rests on the base strip, ship stays above it), or ←/→, A/D, mouse drag
- **Shoot**: automatic
- **Power-ups**: Twin, Spread, Rapid, Laser (15s each), Bomb, Repair (homeland power), 1-Up
- Best score and distance saved locally. Installable PWA with Share button.

Play: https://marlybiz.github.io/retro-space-shooter/
