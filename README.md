# Retro Space Shooter

Mobile-first arcade shooter (**v2.6**). Ten-level campaign in **light years** (L1=2000, then +500/level, cap 5000). Even levels end with the recurring **GUNSHIP** boss — destroy it on level 10. Network-first PWA updates so you always get the latest build.

**Play:** https://marlybiz.github.io/retro-space-shooter/

- Level lengths: `min(5000, 2000+(level-1)*500)` LY per level; HUD distance is cumulative.
- Touch/drag to move. Auto-fire. Desktop: arrows / A D. Escape/P pauses.
- Power-ups: Twin, Spread, Rapid, Laser, Bomb, Repair, 1-Up.
