# Retro Space Shooter

Mobile-first arcade shooter (v2.5). Ten-level campaign in **light years**. Levels unlock new foes (easier ships stay more common). Even levels end with the recurring **GUNSHIP** boss — destroy it on level 10 for victory. Pause/auto-pause with CONTINUE after close.

**Play:** https://marlybiz.github.io/retro-space-shooter/

- Level lengths: min(5000, 2000+(level-1)*500) LY.
- Touch/drag to move. Auto-fire. Desktop: arrows / A D. Escape/P pauses.
- Power-ups: Twin, Spread, Rapid, Laser, Bomb, Repair, 1-Up.
- Best score and distance saved locally. Installable PWA with Share button.
